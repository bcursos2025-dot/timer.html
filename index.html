Ver como instalar

Instalação assistida

  1. Baixe os arquivos do instalador.
  2. Dê dois cliques no .bat: ele confere, extrai e abre o navegador.
  3. No navegador, ligue o modo do desenvolvedor e carregue a pasta (3 cliques).

O Windows pode mostrar um aviso para arquivos novos baixados da internet. A página de instalação explica o porquê e como conferir o arquivo.

Dúvidas

Perguntas frequentes

Preciso criar conta?

Não para começar. Os seus dados ficam salvos neste aparelho. A conta, para sincronizar entre aparelhos, está nos planos.

Funciona sem internet?

Sim. O cronômetro e os cartões de revisão funcionam sem internet, e os dados ficam no seu aparelho.

É só para a OAB?

O foco agora é a OAB, mas você pode escolher o perfil de concurso público na primeira tela e trocar quando quiser em Ajustes.

A correção de peça por IA já existe?

Ainda não. Ela está em desenvolvimento e aparece como “em breve” enquanto isso. Não vamos anunciar como pronta antes de funcionar.

Preciso instalar a extensão?

Não. O site funciona sozinho. A extensão é opcional e deixa o estudo no computador mais completo.

A extensão é segura?

O instalador é um arquivo de texto que você pode abrir e ler, não pede administrador e não altera o registro do Windows nem as configurações do navegador. A página de instalação mostra o código de conferência (SHA-256) do arquivo.
